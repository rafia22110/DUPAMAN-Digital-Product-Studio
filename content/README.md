## בקרת איכות (טיוטה מול מאושר)
* כל קובץ שמתחיל ב-`_` (כמו `_template.example.json` / `_template.example.md`) — **לא מוצג באתר**.
* כל קובץ שמכיל `"draft": true` או `"approved": false` — **נשאר בטיוטה ולא עולה לאתר** עד שתאשר (`"approved": true`).
