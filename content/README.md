# מאגר התכנים של DUPAMAN (`content/`)

תיקייה זו היא מאגר התכנים המרכזי של האתר. כל קובץ `.json` שנוסף לכאן נטען אוטומטית אל האתר ואל **הבוט החכם של דופמין** (קבצים שמתחילים בקו תחתון `_` כמו `_template.example.json` אינם מוצגים באתר).

## מבנה התיקיות
* `01-news-and-guides/` — חדשות ומדריכים (מוצגים רק תכנים חדשים עד **30 יום**)
* `02-education/` — חינוך ולמידה פעילה (פעילויות חינוכיות, העלאת תכנים ללמידה)
* `03-psychology-health/` — פסיכולוגיה ובריאות
* `04-ai-academy/` — בינה מלאכותית יוצרת (אקדמיה ברשת ומדריכים מקוריים)
* `05-neuroscience-innovation/` — מדעי המוח וקוגניציה (מאגרי חדשנות)
* `06-science-projects/` — מדע, פיזיקה ואסטרונומיה
* `shared/` — תכנים חוצי-תחומים שמתאימים לכמה כרטיסיות במקביל

## איך מוסיפים תוכן שמתאים לכמה כרטיסיות ולבוט?
כל פריט במאגר כולל שני שדות מפתח:
1. **`cards`**: מערך מספרי הכרטיסיות שבהן התוכן יופיע (`"01"`, `"02"`, `"03"`, `"04"`, `"05"`, `"06"`).
   * לדוגמה: `"cards": ["02", "04"]` יציג את התוכן גם ב**חינוך ולמידה פעילה** וגם ב**בינה מלאכותית יוצרת**.
2. **`tags`**: מערך תגיות חופשי בעברית או באנגלית (לדוגמה: `["חינוך", "בינה מלאכותית", "סדנה", "קשב"]`).
   * הבוט החכם קורא את כל התגיות כדי לאתר ולהמליץ על התוכן המדויק.
   * בנוסף, המערכת יודעת להתאים אוטומטית תגיות מפתח גם לכרטיסיות נוספות (`autoMatchByTags: true`) כדי שלא יתפספס אף תוכן.

## כלל 30 הימים לכרטיסייה `01` (חדשות ומדריכים)
* פריט שמשויך לכרטיסייה `"01"` צריך לכלול:
  * `"section": "news"` (חדשות) או `"section": "guides"` (מדריכים)
  * `"publishedAt": "YYYY-MM-DD"` — האתר מסנן אוטומטית ומציג רק תכנים בני **30 יום ומטה**.
